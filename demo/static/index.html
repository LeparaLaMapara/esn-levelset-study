Learning the level set

A Chan-Vese level set runs live on this server, one iteration at a time. Underneath, four kinds of recurrent model try to predict where the front moves next: two of them are reservoirs whose recurrent weights are never trained.

1. The level set, running now

This is the data generator of the study, executing on request. Change the parameters and the partial differential equation is solved again from the checkerboard start.

2. What each model predicts

Given the last few masks, each model predicts the mask ten iterations ahead. The orange panel is the region that actually changes, which is the only part of the image where the models can distinguish themselves: predicting no change at all already scores about 0.99 on a whole image IoU.
